# Tasks for Antigravity (agy)

Paste one task file at a time into agy. Rules that apply to **every** task:

1. **Write only to the paths listed in the task.** Do not edit any other file.
2. **Do not `git commit` or `git push`.** Claude Code reviews, integrates and commits your output.
3. **Cite every factual rule or number**: name the document, clause or section, and edition/year. If you cannot find a source, write `"source": null, "confidence": "low"`. Never invent a clause number.
4. **Every rule or number you produce is unverified**: set `"verified": false`. Only a licensed professional flips it to true.
5. Output must be valid JSON where the task says JSON. When you finish, append a short "done + caveats" note at the bottom of the task file.
