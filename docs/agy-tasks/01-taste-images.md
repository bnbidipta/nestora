# agy task 01: Taste images, card catalogue and taxonomy

Follow the rules in `docs/agy-tasks/README.md`.

**Write only to:** `docs/taste-taxonomy.md`, `frontend/public/swipe/`, `backend/app/data/swipe_cards.json`

## Goal
Nestora learns a user's home-style taste by having them keep or discard image cards. Today the 30 cards are text-only and the taste vector is fake. The new model keeps an explicit preference for each style and each attribute axis, so every card needs those labels attached.

## Deliverables
1. **`docs/taste-taxonomy.md`**
   - **Styles:** 5 core styles (`japanese`, `biophilic` (was "forest"), `brutalist`, `minimalist`, `indian_heritage` (was "old_is_gold")), plus up to 3 globally popular extras you recommend (e.g. `scandinavian`, `mediterranean`, `industrial`), each with a one-line justification.
   - **Axes:** 6-8 attribute axes, each scored -1..1:
     - `palette_warm_cool`
     - `ornament_minimal_ornate`
     - `material_wood_stone_concrete` (split this into 3 axes if that's clearer)
     - `light_bright_moody`
     - `space_open_cozy`
     - `era_modern_traditional`
     - `greenery_none_lush`
   - **Table:** each style's typical value on every axis.
   - **Opening set:** recommend the **10-12 cards to show first**, the ones that best separate the styles and axes.
2. **`frontend/public/swipe/`**: 6 images per style plus 6 mixed "tie-breaker" images.
   - Format: 1200x900 WebP, under 200 KB each.
   - Content: residential, interior and exterior, with Indian-home context where natural (Mumbai light, Indian materials and furniture), but globally appealing.
   - Source: Unsplash or Pexels (free licence, commercial use OK), or AI-generated by you. No other sources.
3. **`backend/app/data/swipe_cards.json`**: an array with one entry per image:
   ```json
   {"id":"jp_living_01","file":"/swipe/jp_living_01.webp","deck":"exterior|living|kitchen|bedroom|materials|colour",
    "style":"japanese","attributes":{"palette_warm_cool":0.4,"...":0},
    "source":"unsplash|pexels|generated","licence":"Unsplash License","author":"Name","url":"https://...","alt":"Short description for screen readers"}
   ```
   Every non-generated image must have `author`, `licence` and `url` filled in (needed for attribution). `alt` is required on every card.

## Done when
- The JSON parses and the number of entries equals the number of image files.
- Every style has ≥ 6 cards.
- Every attribute value is within -1..1.
